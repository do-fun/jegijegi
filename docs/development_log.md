# JEGI JEGI Development Log

## 2026-08-18

### 사용자 결정

- 게임 규칙과 제품 설계는 `docs/design_doc.md`에만 기록한다.
- 서브는 새로운 차기 입력으로만 시작하고 키보드 자동 반복을 허용하지 않는다.
- 스테이지 목표는 최소 성공 횟수이며 제한시간 종료까지 초과 기록을 계속 누적한다.
- 타임오버 프레임에는 모든 행동을 정지하고 스테이지 판정을 우선한다.
- 제한시간 전에 생명이 0이 되면 목표 달성 여부와 관계없이 `GAME OVER`로 처리한다.
- 모바일 입력은 추후 별도로 결정한다.
- 추후 모바일 앱스토어 출시와 광고 도입 가능성을 고려하되 첫 웹 버전에는 광고 SDK를 넣지 않는다.

### Codex 구현

- 타이틀 다음에 한 화면형 튜토리얼 Scene을 추가했다.
- 키보드를 공통 action으로 변환하는 `InputManager`를 추가했다.
- 서브, 좌우 이동, 차기 모션, Good·Perfect 판정과 제기 궤도를 구현했다.
- 점수, 콤보, 생명, 스테이지 목표, 제한시간, 5초 서브 대기 페널티를 구현했다.
- 스테이지 클리어, 재도전, `GAME OVER`, `ALL CLEAR` 상태 전이를 구현했다.
- 최고 점수, 최대 콤보와 스테이지별 성공 기록을 `localStorage`에 저장한다.
- 설계된 구간별 파리 수와 날씨 선택을 순수 함수로 구현했다.
- 비, 바람, 파리 충돌과 벌레 보너스의 첫 구현을 추가했다.
- 포커스 이탈 시 게임 상태와 입력을 일시 정지하도록 구현했다.
