# JEGI JEGI Development Log

## 2026-08-19

### 사용자 결정

- 기능 테스트 다음 단계로 옛날 8비트 게임 스타일 사운드를 적용한다.

### Codex 구현

- 외부 음원 없이 직접 합성한 8비트풍 루프 BGM과 효과음·주변음 WAV 에셋을 추가했다.
- 차기, Good·Perfect, 연속 Perfect 음높이, 벽 반사, 파리 충돌, 바닥 실패, 5초 경고, 복주머니, 스테이지 결과, 생명 보상, 방해 요소 등장, Game Over와 All Clear 사운드를 연결했다.
- 비·바람·파리 반복 주변음을 추가하고 파리 거리에 따라 날갯소리 음량이 제한적으로 변하도록 했다.
- 음소거 상태 저장, 브라우저 포커스 이탈 시 반복음 일시 정지, 결과 화면 BGM 덕킹을 적용했다.
- 타이틀의 게임 시작 확인음이 다른 소리를 압도하지 않도록 음량을 낮췄다.
- 효과음 전체에 공통 음량 감쇠를 적용하고 BGM을 소폭 올렸으며, 겹쳐 재생되는 차기·Good·Perfect 음량을 추가 조정했다.
- HUD 스피커 버튼을 카드 안쪽에 맞는 크기와 둥근 음파 형태로 다듬었다.
- 기존 제기 이미지를 파비콘으로 지정해 브라우저의 `favicon.ico` 404 요청을 제거했다.
- 서브·차기·실패 순간의 프레임 끊김을 줄이기 위해 모든 효과음 객체를 타이틀에서 미리 준비하고 재사용하도록 변경했다.
- Good·Perfect·최대 연속 Perfect를 스테이지별로 누적하고, 스테이지 종료·Game Over·All Clear 결과에 전체 및 스테이지별 기록을 표시하도록 구현했다.
- 다음 스테이지 진입 시 콤보, 연속 Perfect와 Perfect 효과음 음높이를 모두 초기화하도록 변경했다.
- 스테이지 결과의 자동 전환을 제거하고 `아무 버튼이나 눌러 계속` 안내와 키보드·포인터 계속 입력을 추가했다.
- 스테이지 결과와 Game Over의 텍스트 나열을 요약 카드와 정렬된 스테이지별 기록 표로 교체했다.
- 성공 횟수 카드의 포괄적인 제목을 `차기 성공 / 목표`로 바꿔 수치의 의미를 명확히 했다.
- 튜토리얼 확인 여부를 세션 단위로 변경하고, 타이틀에 원형 아이콘·말풍선 안내와 `R` 키를 사용하는 2단계 로컬 기록 초기화 기능을 추가했다.
- 올 클리어 기록 화면 위에 겹치던 축포 장식을 제거해 표와 점수 카드의 가독성을 높였다.
- 전체 기능 플레이 테스트를 위해 임시 적용했던 LIFE 무제한 모드를 제거하고 원래 생명 감소·GAME OVER 규칙으로 복구했다.
- 대회 제출 URL에 계정 서브도메인이 노출되지 않도록 Cloudflare Pages 설정과 재현 가능한 `npm run deploy` 명령을 추가하고 프로덕션 빌드를 배포했다.

## 2026-08-18

### 사용자 결정

- 게임 규칙과 제품 설계는 `docs/design_doc.md`에만 기록한다.
- 서브는 새로운 차기 입력으로만 시작하고 키보드 자동 반복을 허용하지 않는다.
- 스테이지 목표는 최소 성공 횟수이며 제한시간 종료까지 초과 기록을 계속 누적한다.
- 타임오버 프레임에는 모든 행동을 정지하고 스테이지 판정을 우선한다.
- 제한시간 전에 생명이 0이 되면 목표 달성 여부와 관계없이 `GAME OVER`로 처리한다.
- 모바일 입력은 추후 별도로 결정한다.
- 추후 모바일 앱스토어 출시와 광고 도입 가능성을 고려하되 첫 웹 버전에는 광고 SDK를 넣지 않는다.

### Codex 구현

- 타이틀 다음에 한 화면형 튜토리얼 Scene을 추가했다.
- 키보드를 공통 action으로 변환하는 `InputManager`를 추가했다.
- 서브, 좌우 이동, 차기 모션, Good·Perfect 판정과 제기 궤도를 구현했다.
- 점수, 콤보, 생명, 스테이지 목표, 제한시간, 5초 서브 대기 페널티를 구현했다.
- 스테이지 클리어, 재도전, `GAME OVER`, `ALL CLEAR` 상태 전이를 구현했다.
- 최고 점수, 최대 콤보와 스테이지별 성공 기록을 `localStorage`에 저장한다.
- 설계된 구간별 파리 수와 날씨 선택을 순수 함수로 구현했다.
- 비, 바람, 파리 충돌과 벌레 보너스의 첫 구현을 추가했다.
- 포커스 이탈 시 게임 상태와 입력을 일시 정지하도록 구현했다.
